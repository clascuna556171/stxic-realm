# STXIC Realm logo kit

> **Design update:** The owner prefers a simpler, flat logo direction shown in [Visual direction](VISUAL_DIRECTION.md). This document describes the existing SVG kit, which has not yet been replaced by the concept.

Redesigned 28 October 2026 as a Realm “R” with a curved bowl, open counter and detached sweeping leg. The supplied reference informed its flowing curves and use of negative space; the composition is a new design, a custom path-drawn two-line wordmark reads STXIC Realm. The design is proposed pending owner review. Rights to the supplied reference, similarity to existing marks, and trademark availability have not been assessed; verify before public use or launch.

Assets: `apps/web/public/brand/` (SVG, scalable and editable). The main mark and wordmark have transparent backgrounds. The favicon has a graphite tile.

- `realm-logo-horizontal-{light,dark,violet}.svg`: primary symbol-and-name lockup.
- `realm-logo-stacked-{light,dark,violet}.svg`: centered compact lockup.
- `realm-symbol-{light,dark,violet}.svg`: mark alone for compact surfaces.
- `realm-wordmark-{light,dark,violet}.svg`: name alone.
- `realm-favicon.svg`: small browser icon on a graphite tile.
- `archive/orbit-v2/`: earlier orbital logo kit.
- `archive/reference-adaptation/`: previous close reference adaptation.
- `index.html`: visual sheet; open `/brand/index.html` while running the web app.

**Light** means light artwork for dark backgrounds; **dark** means dark artwork for light backgrounds. Violet is an accent variant and must have enough contrast against its background. Keep the mark proportions intact and leave breathing room around the artwork. Use the full lockup where room permits and the symbol for small app navigation; do not stretch or add gradients and shadows. Check legibility at the intended size. The lettering is drawn as paths, not live text, so it renders consistently without a font dependency.
