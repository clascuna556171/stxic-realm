# Server Halls visual implementation

**Superseded by [Hall Studio and visual consistency](HALL_STUDIO.md):** the hall is now assembled from editable pixel components with three environment themes. The illustrated background described below is preserved for provenance at `images/great-hall-illustrated-v1.webp` and is no longer shipped in `public/`. The following sections record the first visual pass.

29 October 2026. Implements the owner's visual-overhaul brief in `apps/web`, starting with Server Halls. The existing React/Vite/Supabase architecture, logo and user data formats are retained.

## Direction and implementation

The great hall is a gathering place with weathered limestone, oak rafters, heraldic banners, warm candlelight, cool night windows and a clear central path. It takes the material detail and inhabited atmosphere of `images/realm-room-character-concept-v3.png` into a larger architectural space. The explicit medieval pixel-art brief governs this direction. The interface uses a self-hosted Pixelify Sans display face, restrained brass controls, legible conventional text and a quiet charcoal shell.

- `ServerHall.tsx` shares selection between three spatial entrances per wing and a searchable directory. Longer memberships get previous/next wing controls. The user's actual avatar moves to the selected entrance. No character animation or simulated player presence is implied.
- `Spaces.tsx` remains the membership-authorized route (`/?spaces`). Its existing invitations, creation, channels, membership, moderation and account controls are available in the expandable **Manage spaces** area. Join/create links open it. The backend still calls servers **spaces**.
- **Enter server** and channel links pass `space`/`channel` IDs into chat, which validates them against the membership-scoped query results. Archived history remains readable; closed servers cannot be entered from the hall.
- `/?hall-preview` reuses the environment with explicitly illustrative servers and a sign-in action. It is linked from sign-in and the anonymous Halls navigation. It grants no membership or access.
- CSS ambient light and nine small embers require no animation dependency or WebGL. The effects toggle removes the embers; reduced motion disables animation and traveler transitions. Scene loading, image failure, no membership, search misses and backend errors have text equivalents and recovery controls.
- The hall is lazy loaded. The 1536 × 1024 runtime WebP is approximately 556 KiB. The existing room renderer remains lazy loaded separately.
- `world/CharacterAlcove.tsx` extends the hall's masonry, brass and heraldry into the character stage. The 48 × 64 modular sprite now has more restrained eye highlights and skin shading; all saved customization values remain compatible.
- `world/lighting.ts` shares source-positioned lighting between static SVG rooms and Phaser. Lights follow moved furniture and disappear with removed sources. Medieval room masonry, carved uprights and wine-red banners join the hall's material vocabulary. Object inspection, layout validation, movement and undo/redo remain intact.

## Assets and provenance

The hall backdrop was generated with the built-in image-generation tool using the supplied concept as a style reference. It contains no interface text or people; React supplies all live names and interactions. Source: `images/great-hall-source.png`. Runtime: `../apps/web/public/world/great-hall.webp`. WebP conversion used ffmpeg quality 88. Original SVG crests, the alcove and all configurable characters remain code assets. The Pixelify Sans font and its SIL Open Font License are in `../apps/web/public/fonts/`.

Final generation prompt:

> Use case: stylized-concept. Asset type: original production pixel-art environment backdrop for STXIC Realm, an interactive medieval gathering hall in a web app. Generate one wide landscape 3:2 image, no UI, absolutely no text or lettering, no people or characters. Primary reference is the attached room concept: finely handcrafted mature pixel art, consistent tiny pixel grid, layered shading and cozy living detail, classic RPG/Terraria atmosphere. Transform that art direction into an impressive grand guild hall interior seen front-on from a slightly raised 2D cutaway camera. Entire room visible. Three distinct arched entrances spaced across the back wall, centered approximately at 25%, 50%, and 75% of the image width, with door thresholds at 56% image height. Left entrance has forest green banners and oak doors, middle entrance is grand warm amber stone arch and open dark doorway, right entrance has faded blue banners and a blue moonlit doorway. Each entrance has a broad unobstructed stone landing in front for interactive labels placed later by code. Tall detailed limestone and charcoal stone block walls, heavy dark timber rafters, medieval heraldry without letters, wrought iron chandeliers with warm candles, ornate carved columns, iron sconces, rich burgundy runner rug leading from central doorway toward foreground bottom center. Foreground corners contain round wooden gathering tables, stools, books, mugs, plants, a notice board on left, a stone fireplace on right. Abundant rich detail but clear large architectural forms. Ivy, library shelves, weathered stonework, warm pools of golden torch light against cool desaturated blue shadows, luminous dust motes. Deep comfortable warm night palette: dark charcoal, brown oak, sage green, antique brass, amber flame, muted teal. Wide strong balanced composition filling entire frame edge to edge. Leave center floor spacious. No glossy 3D, no photorealism, no anime, no childish cartoon, no blurred painterly shapes, no gradients as UI, no interface frames. Authentic crisp pixel art with 2-3px visual pixel scale at 1536px width. This is final runtime environment art, not a screenshot or website mockup.
